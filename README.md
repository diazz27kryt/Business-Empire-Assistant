# Business Empire Assistant

Android companion for Business Empire: RichMan. This project is an independent helper; it does not modify the game or access its private data.

## Features planned
- Manual portfolio and asset tracking
- Screenshot-based quote entry (OCR planned)
- Profit and payback calculators
- Transparent trend analysis based only on recorded observations

## Build
GitHub Actions builds a debug APK on pushes to `main` and manual workflow runs.
